# User stories (priority order)

1. As a visitor I want to open a production portal so I can see available performances.
2. As a new user I want to register under a specific production so I can book performances for that production.
3. As a registered user I want to add performances to a basket and review totals before payment.
4. As a registered user I want to upload proof of payment so the production can confirm my booking.
5. As a production manager I want to view bookings on a calendar and click a date to see booking details.
6. As an admin I want to view all productions and suspend a production if subscription expired.
